# Huellitas de Esperanza – Campaña de Esterilización

## 1. Project Description
Landing page informativa y de conversión para la campaña social de esterilización masiva de perros y gatos de "Huellitas de Esperanza – Protección y Defensa Animal". Público objetivo: dueños de mascotas de la zona que buscan información clara y un canal directo (WhatsApp) para inscribirse. Valor central: informar con confianza y convertir visitas en inscripciones por WhatsApp.

## 2. Page Structure
- `/` - Landing única de la campaña (hero, banner de cupos, información, beneficios, requisitos, qué incluye, ubicación, inscripción, footer).

## 3. Core Features
- [ ] Hero con CTA principal a WhatsApp y CTA secundario a requisitos
- [ ] Banner de cupos limitados
- [ ] Cards de información de campaña (fecha, lugar, precios)
- [ ] Sección educativa de beneficios de la esterilización
- [ ] Sección de requisitos previos
- [ ] Sección de qué incluye el proceso
- [ ] Sección de ubicación con mapa embebido y "Cómo llegar"
- [ ] Sección de inscripción/contacto por WhatsApp con mensaje prellenado
- [ ] Footer con identidad de la organización
- [ ] Botón flotante de WhatsApp

## 4. Data Model Design
No requiere base de datos. Contenido estático de campaña.

## 5. Backend / Third-party Integration Plan
- Database: no requerida
- Shopify: no requerido
- Stripe: no requerido
- Others: WhatsApp como canal de contacto (enlace wa.me)

## 6. Development Phase Plan

### Phase 1: Landing completa de la campaña
- Goal: entregar la landing responsive con todas las secciones informativas y los CTA de WhatsApp funcionando.
- Deliverable: página `/` maquetada, con identidad visual verde/amarillo, imágenes emotivas, mapa y botón flotante de WhatsApp.

### Phase 2 (opcional): Ajustes de contenido y SEO
- Goal: refinar textos, metadatos y detalles de conversión según feedback.
- Deliverable: mejoras incrementales solicitadas por el usuario.
